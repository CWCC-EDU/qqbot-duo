# 千鸟酱与菲姆酱（Seraphim）

基于 NoneBot2 和 OneBot v11 的两套 QQ 群机器人源码，使用 NapCat 等 OneBot 服务连接 QQ。两台机器人独立运行、独立保存数据。

## 功能

- 技能决斗、快速决斗、赛马、签到、藏品、娶群友和今日小猪。
- 本地词库与群聊学习、可选 DeepSeek 云聊、固定人格与分群记忆。
- 图片帮助、群语录、漂流瓶、表情包及群管理。
- 日/周/月/年词云和发言排行。
- 群忙自动判断、每天定时时段、延后汇总、滚动触发限流。
- 词库查询一次最多20张清晰图片，放进一条合并转发记录，支持继续查询和文字模式。

## 运行前准备

本仓库是经过数据剥离的源码发行版，不包含已登录的 QQ 客户端、Python 便携环境、运行数据库或聊天记录。不是服务器目录的整盘备份。

使用 Python 3.12，建议每台服务器新建独立虚拟环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe run.py testbot --prepare
.\.venv\Scripts\python.exe run.py testbot_2 --prepare
```

编辑各自的 `.env`，填写自己的超管 QQ 和 OneBot token；两台监听端口分别为8080、8081。NapCat 的反向 WebSocket 分别连接 `ws://127.0.0.1:8080/onebot/v11/ws` 和 `ws://127.0.0.1:8081/onebot/v11/ws`，token 与各自环境文件一致。

按 [资源说明](docs/ASSETS.md) 自行补齐有权使用的素材。原机器人部分功能需要字体、求签图、原第三方插件资源或本地绘图库兼容版本；不能把“源码语法通过”当作全新环境全部功能可直接用。

```powershell
.\.venv\Scripts\python.exe run.py testbot
# 在另一终端运行
.\.venv\Scripts\python.exe run.py testbot_2
```

首次运行应检查插件加载日志。依赖清单来自本地已有环境和已知版本，尚未在全新机器联网重建所有依赖；部分老插件需要对应资源或另行配置。`bot.py` 保留功能清单，停用某项可注释其加载行。

## 云聊

云聊是可选功能。通过本地 `DEEPSEEK_API_KEY` 环境变量或本机 `runtime/deepseek.key` 配置自己的密钥。仓库不包含任何有效密钥。费用、模型分工、人设和分群开关按源码配置；公开版不预设原作者的群号，也不自动打开原群云聊。

## 功能指令

- `帮助`：根据权限显示功能菜单。
- `今日词云`、`本周词云`、`本月词云`、`年度词云`，以及对应发言排行。
- `查询词库`：图片合并记录；`查询词库 从第21张`：继续查看。
- `群忙合并 自动`、`设置群忙阈值 60 20 4`、`设置群忙汇总 60 10`、`设置群忙限流 60 3`。

详细群忙设置、权限及恢复机制见 [群忙说明](docs/GROUP_BUSY.md) 和 [词库查询说明](docs/WORD_BANK.md)。
