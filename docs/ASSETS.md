# 资源与数据

公开仓库不包含 `.env`、DeepSeek密钥、QQ登录缓存、聊天记录、群友画像、知识库、语录存档、签到/好感/配对数据库及运行日志。

以下资源需部署者自行准备并确保有权使用：

1. 千鸟求签图：`testbot/testbot/plugins/testforsera/fortune_cards/`，按现有 `cards.json` 放置PNG。此清单描述8角色64张，角色/档位概率逻辑保留。
2. 菲姆原版求签：`testbot_2/data/gacha/`。至少放入一张有权使用的图片。
3. 原版图片生成器的模板、字体、图标及部分玩法的静态资源。以对应插件的上游资源说明和启动日志为准；不要将群友头像库或私聊截图作为仓库资源上传。
4. 原版藏品定义和其他数据库：请用管理功能或自行创建的空白定义初始化，勿把服务器旧数据库发布。

独立部署不会继承作者原来的好感、婚姻、群配置或群友记忆。`defaults/` 只包含经过筛选的静态规则和文案，不含历史用户状态。

缺少资源的功能可暂时在各 `bot.py` 中注释加载行。此源码发行没有承诺在未补齐资源的空机器上全部历史插件零配置可用。
